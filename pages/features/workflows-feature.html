Triggers

React to every change in real time

Workflows fire the moment something meaningful happens in your CRM. No polling. No delays. Just instant execution.

  • Record Created: Company, Person, or Opportunity added to your CRM
  • Record Updated: Any field change on any object fires the chain
  • Task Created: New task triggers follow-on automations across deals and contacts

Actions

Do the work your team forgets

Stack multiple actions in a single workflow. Each one runs in order, automatically. No matter how busy the day gets.

  • Create records: new companies, people, or opportunities
  • Update existing records: advance a deal stage, update a field value
  • Create or update tasks. Assign, prioritize, and set due dates automatically

How it works

Three steps to automated

New Lead Nurture

When a Company is created with type "Prospect" → create an intro task + move linked opportunity to Qualification.

Deal Stage Advance

When an Opportunity is updated to "Proposal" → create a follow-up task with a 3-day deadline for the deal owner.

Task Auto-assign

When a Task is created without an assignee → assign it to the company's owner and set priority to Medium automatically.

Post-Call Follow-up

When a Person record is updated after a call → create a "Send follow-up email" task and set the opportunity's next step date.

Win / Loss Logging

When an Opportunity moves to Closed-Won → create an onboarding task. When Closed-Lost → update company type to "Dormant".
